# 会话控制

帮助用户开始一段干净的会话，或了解如何清除当前上下文。

## 明确命令

用户单独发送下列任一命令时，宿主会在 Agent 调用前完成操作：

- `清除上下文`
- `清除会话`
- `重置会话`
- `新建会话`
- `切换会话`

这些命令会清除当前会话的 Claude resume 链和关联记忆。群聊按群共享上下文，因此会清除整个群的当前上下文；私聊只影响当前私聊。

## 询问或意愿

用户尚未发送明确命令，但表现出类似询问或意愿时，要主动引导。例如：

- “怎么清除之前的内容？”
- “你能忘掉前面的对话吗？”
- “我想重新开始”
- “能不能开个新会话？”
- “换个话题，不要接着上面聊了”

此时说明影响范围，并请用户单独发送 `清除上下文` 或 `新建会话`。不要把模糊表达直接视为删除确认，也不要继续回答依赖旧上下文的内容。

不要自行删除文件或运行 shell 命令。
